# Valoración inicial

Formulario de inicio para planes personalizados de entrenamiento y nutrición.
Se publica con GitHub Pages; las respuestas se envían a una hoja privada de Google Sheets mediante Apps Script.
Este repositorio solo contiene la página, nunca las respuestas.

## Formularios

| Formulario | Para quién | Link | Carpeta |
|---|---|---|---|
| Valoración inicial | Clientes nuevos | `https://alfred9573.github.io/valoracion/` | raíz |
| Check de seguimiento | Clientes que ya llevan plan | `https://alfred9573.github.io/valoracion/checks/` | [`checks/`](checks/) |

Cada uno tiene su propio Apps Script y su propia hoja de respuestas. Las
instrucciones de montaje del check están en [`checks/README.md`](checks/README.md).
